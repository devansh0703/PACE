# pace-sdk — commercial product site

Astro static site. Deploys to GitHub Pages.

```bash
npm install
npm run dev      # local dev server
npm run build    # produces dist/
npm run preview  # serves the built site
```

Design language: "Wire Terminal" — a field-instrument aesthetic. Warm
charcoal ground, amber accent, IBM Plex Mono for structure and all numerics,
Phosphor icons at light weight, 3px radii, borders for elevation, and
severity-only saturated colour. No gradients, no glassmorphism, no emoji
icons, no pill badges, no numbered step lists, no stat banner rows.

Every number on the site comes from a committed measurement artifact in
`pace-sdk/results/`.
